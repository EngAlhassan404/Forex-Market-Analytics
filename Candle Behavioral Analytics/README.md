## ماذا يفعل الإكسبرت؟

عند التشغيل، يقوم الإكسبرت بالآتي:

1. يقرأ عددًا محددًا من الشموع المغلقة على `InpTimeframe` أو يقرأ كامل التاريخ المتاح.
2. يصنف كل شمعة:
   - **Bullish** إذا كان `Close > Open`.
   - **Bearish** إذا كان `Close < Open`.
   - الشموع التي تحقق `Close == Open` لا تدخل في أي مجموعة.
3. يحسب لكل مجموعة مؤشرات الحركة المواتية والمعاكسة:
   - MFE.
   - MAE.
   - الوسيط.
   - المتوسط الحسابي.
   - الانحراف المعياري.
4. يبني نطاقًا تنبؤيًا حول المتوسط باستخدام الانحراف المعياري.
5. يرسم على الشارت مستويات حركة صاعدة وهابطة متوقعة، مع لوحة معلومات قابلة للسحب والطي.
6. يعيد الحساب عند ظهور شمعة جديدة من الإطار الزمني المستهدف، ويحافظ على تحريك تسميات الخطوط أثناء تكون الشمعة الحالية.

> التحليل التاريخي يستخدم الشموع المغلقة فقط؛ فالشمعة ذات الفهرس `0` مخصصة للإسقاط الحالي ولا تدخل في العينة التاريخية.

## المقاييس والمفاهيم

### 1. السعر المفتوح والمغلق والعالي والمنخفض

لكل شمعة:

- `Open`: سعر افتتاح الشمعة.
- `Close`: سعر إغلاق الشمعة.
- `High`: أعلى سعر خلال الشمعة.
- `Low`: أدنى سعر خلال الشمعة.

تُستخدم هذه القيم لقياس أقصى امتداد سعري داخل الشمعة، وليس لقياس نتيجة صفقة فعلية بعد احتساب السبريد أو العمولة أو الانزلاق السعري.

### 2. MFE — Maximum Favorable Excursion

**الاسم الكامل:** Maximum Favorable Excursion  
**الترجمة:** أقصى حركة مواتية.

في هذا الإكسبرت، تمثل MFE أكبر امتداد داخل الشمعة في اتجاه لونها:

#### للشمعة الصاعدة

```text
MFE_bull = (High - Open) / UnitDivider
```

#### للشمعة الهابطة

```text
MFE_bear = (Open - Low) / UnitDivider
```

أي أن MFE لا تستخدم `Close`؛ بل تستخدم أقصى `High` أو `Low` وصلت إليه الشمعة من سعر الافتتاح.

### 3. MAE — Maximum Adverse Excursion

**الاسم الكامل:** Maximum Adverse Excursion  
**الترجمة:** أقصى حركة معاكسة.

في هذا الإكسبرت، تمثل MAE أكبر امتداد داخل الشمعة عكس اتجاه لونها:

#### للشمعة الصاعدة

```text
MAE_bull = (Open - Low) / UnitDivider
```

#### للشمعة الهابطة

```text
MAE_bear = (High - Open) / UnitDivider
```

لذلك فإن MFE وMAE هنا وصفيتان لسلوك الشمعة حول الافتتاح، وليستا محاكاة كاملة لصفقة لها نقطة دخول ووقف وهدف.

### 4. وحدة القياس: النقاط أو البيب

يحوّل الإكسبرت فرق السعر إلى وحدة عرض باستخدام `UnitDivider`:

- في الرموز ذات 3 أو 5 خانات عشرية: `UnitDivider = _Point × 10` عند العرض بالبيب.
- في غير ذلك: `UnitDivider = _Point`.
- عند اختيار **Points** تكون الوحدة دائمًا `_Point`.

في وضع `UNIT_AUTO` يختار الإكسبرت البيب للرموز ذات 3/5 خانات، والنقاط لبقية الرموز. هذا الاختيار مناسب غالبًا للفوركس، بينما قد يكون عرض النقاط أكثر وضوحًا لبعض المؤشرات والذهب والسلع.

### 5. المتوسط الحسابي — Arithmetic Mean

**الاسم الكامل:** Arithmetic Mean  
**الترجمة:** المتوسط الحسابي.

لعدد `n` من القيم `x₁, x₂, ..., xₙ`:

```text
Mean = (x₁ + x₂ + ... + xₙ) / n
      = Σxᵢ / n
```

يحسب الإكسبرت متوسط MFE ومتوسط MAE بشكل منفصل للشموع الصاعدة والهابطة. المتوسط هو الأساس الذي تُبنى حوله القيم التنبؤية.

### 6. الوسيط — Median

**الاسم الكامل:** Median  
**الترجمة:** الوسيط.

بعد ترتيب القيم تصاعديًا:

- إذا كان `n` فرديًا، فالوسيط هو القيمة الموجودة في المنتصف.
- إذا كان `n` زوجيًا، فالوسيط هو متوسط القيمتين الوسطيتين:

```text
Median = (x[n/2] + x[n/2 + 1]) / 2
```

يستخدم الإكسبرت الوسيط لعرض قيمة أكثر مقاومة للقيم المتطرفة. وهو لا يدخل في معادلة الإسقاط التنبؤي الحالية؛ التنبؤ مبني على المتوسط والانحراف المعياري.

### 7. الانحراف المعياري — Population Standard Deviation

**الاسم الكامل:** Population Standard Deviation  
**الترجمة:** الانحراف المعياري للمجتمع.

بعد حساب المتوسط `μ`:

```text
σ = √( Σ(xᵢ - μ)² / n )
```

يستخدم الكود المقام `n`، وليس `n - 1`، ولذلك فهو انحراف معياري للمجتمع وليس تقديرًا للعينة (Sample Standard Deviation).

يوجد معاملان مرتبطان بالانحراف:

- `InpSDMultiplier`: يضرب الانحراف المعياري المعروض في لوحة الإحصاءات التاريخية.
- `InpPredSDMultiplier`: يحدد اتساع نطاق التنبؤ.

مهم: نطاق التنبؤ يستخدم الانحراف الخام قبل ضربه في `InpSDMultiplier`.

### 8. النطاق التنبؤي

لكل من MFE وMAE ولكل اتجاه، يحسب الإكسبرت:

```text
PredictionValue = Mean + (RawSD × InpPredSDMultiplier)
PredictionMin   = max(0, Mean - (RawSD × InpPredSDMultiplier))
PredictionMax   = Mean + (RawSD × InpPredSDMultiplier)
```

يتم منع الحد الأدنى من النزول تحت الصفر لأن الامتداد السعري مسافة موجبة. قيمة الخط المرسوم على الشارت هي `PredictionMax`:

- الصعود: خط MFE فوق الافتتاح وخط MAE تحته.
- الهبوط: خط MFE تحت الافتتاح وخط MAE فوقه.
- الخط الصلب يمثل MFE.
- الخط المتقطع يمثل MAE.

هذا النطاق إحصائي وصفي وليس احتمالًا مضمونًا أو فترة ثقة إحصائية، ولا يفترض أن توزيع الحركات طبيعي.

## لوحة المعلومات

تعرض اللوحة:

- الإطار الزمني المستخدم.
- عدد الشموع التي جرى تحليلها.
- وحدة القياس.
- عدد الشموع الصاعدة والهابطة.
- لكل اتجاه: `MFE (الوسيط / المتوسط / الانحراف)` و`MAE (الوسيط / المتوسط / الانحراف)`.
- لكل اتجاه: قيمة MFE وMAE المتوقعة وحدود `[Min - Max]`.

يمكن سحب اللوحة من شريط العنوان، ويمكن طيها أو توسيعها من زر `[-]`/`[+]`.

## المدخلات الرئيسية

| المدخل | الوظيفة |
|---|---|
| `InpTimeframe` | الإطار الزمني للتحليل والإسقاط |
| `InpCalcMode` | عدد شموع محدد أو كامل التاريخ المتاح |
| `InpBarCount` | عدد الشموع عند اختيار نافذة محددة |
| `InpUnitType` | تلقائي، Pips أو Points |
| `InpSDMultiplier` | معامل الانحراف المعروض تاريخيًا |
| `InpPredSDMultiplier` | معامل اتساع النطاق التنبؤي |
| `InpShowLines` | تشغيل أو إخفاء خطوط الإسقاط |
| `InpShowBullLines` / `InpShowBearLines` | إظهار خطوط الصعود أو الهبوط |
| `InpFullWidthLines` | خطوط أفقية كاملة أو مقيدة بفترة الشمعة الحالية |
| `InpShowLineLabels` | إظهار تسميات الخطوط |

## حدود الاستخدام والتفسير

- النتائج تعتمد على الرمز والإطار الزمني ونافذة البيانات المختارة.
- لا يوجد فصل تلقائي بين بيانات التدريب والاختبار.
- لا توجد معالجة للسبريد والعمولة والانزلاق أو السيولة.
- لا يضمن تكرار المتوسط أو الحد الأعلى في الشمعة التالية.
- قلة الشموع الصاعدة أو الهابطة قد تجعل الإحصاءات غير مستقرة.
- الشموع الدوجي مستبعدة، وقد يقلل ذلك العدد الفعلي لكل مجموعة عن عدد الشموع المقروءة.
- المؤشر لا ينفذ صفقات ولا ينبغي اعتباره نظام تداول آليًا مكتملًا.
